📚 How It Works

What is AES?

AES (Advanced Encryption Standard) is a symmetric block cipher that operates on 128-bit blocks. The number of rounds depends on key length: 10 rounds (AES-128), 12 rounds (AES-192), 14 rounds (AES-256).

Key Lengths

AES-128: 10 rounds, fastest, still secure.
AES-192: 12 rounds, balanced.
AES-256: 14 rounds, strongest — recommended for high security.

Modes of Operation

ECB: Each block encrypted independently — insecure for repeated patterns.
CBC: Each block XORed with previous ciphertext (needs IV) — secure.
CFB: Turns block cipher into stream cipher (needs IV) — good for streaming.

Key Handling

Your password is transformed to a key of the selected length using PBKDF2-like stretching via CryptoJS's enc.Utf8.parse + padding. If the password is shorter than required, it is repeated/padded; if longer, it is truncated consistently so encryption and decryption always match.
